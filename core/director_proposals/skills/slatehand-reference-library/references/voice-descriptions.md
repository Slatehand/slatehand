# 音色描述写法

`voice_description` 与旁白的 `zh_voice_description` / `en_voice_description` 会原样作为 Voice Design 的音色描述
提交。模型看不到导演方案、角色卡或画面，只能从这段文字推断嗓音；信息不够时，它会退回该性别年龄最常见的
“好听”嗓音：甜美女声、偶像剧男声、奶声童声、播音腔。人选中的试听会成为参考音频，之后每句对白都克隆它，
再叠加该句的表演指示。所以描述要定下的是这个人平时说话的本嗓，不是某句台词怎么演。

## 写法

按下面顺序写成一段连贯的中文，通常 100–200 字：

1. **先写这是谁、怎样用嗓**：年龄、身份，以及长年塑造这副嗓子的生活，包括职业、环境和用嗓习惯。年龄与身份
   以导演方案为准；方案只给出关系时按关系推算（有六岁孩子的母亲不写成“二十出头”）。只写会落到声音上的事实，
   不写剧情、性格或人物关系。
   - 差：“青年女性，二十多岁，中音偏低，嗓音温和、略带沙质”
   - 好：“三十多岁的草原牧区妇女，常年在旷野里放牧、迎着风沙高声呼唤牲畜”
2. **再写听得出来的声学特征**：音区高低、发声位置与共鸣（胸声、胸腔共鸣、鼻腔共鸣、喉音）、质地（沙哑、
   颗粒感、干涩、粗粝、金属感）、气息（中气足、气息深长、带气声）、咬字（字头有力、收尾利落、咬字偏软）。
   “温和”“干净”“清朗”“好听”这类词只给评价、不给声学特征，会把角色推回默认嗓音，少用。
3. **写明排除项**：点名这个角色最容易被带偏成的默认腔调。常见的有：成年女性的甜美、娇柔、少女感；青年男性的
   偶像剧腔、书生腔、少年奶气；儿童的奶声奶气、撒娇、卖萌、动画配音腔；任何人都可能出现的播音腔、字正腔圆。
   只排除与这个角色冲突的几项，不要每张卡都堆满。
4. **语言与口音**：说汉语的角色写“标准普通话”；方案要求方言或口音时写明具体方言或口音。历史上的、虚构的
   或 TTS 不擅长的语言，不要换成某个现实语种的名称（例如把匈奴语写成“喀尔喀蒙古语”），改写成“说一种陌生的
   游牧民族语言”这类说法，再写元音、辅音的发音质感。台词用拉丁字母转写时加“不带英语口音”，否则模型会按
   英语拼读。
5. **最后固定朗读状态**：以“语速平稳均匀，语调平淡，无明显情绪起伏”收尾。参考音频要用平静的日常朗读录成，
   情绪交给每句对白的表演指示；试听里带上的情绪会被克隆进所有台词。

## 自检

- 把同一项目里几张卡的第 1 步遮住，剩下的描述还分得清是谁吗？各卡除了收尾那句，不能是同一套模板换几个形容词。
- 描述里有没有剧情、情绪、台词内容或人物关系？这些不属于音色，删掉。

## 旁白

旁白同样按这五步写。第 1 步写叙述者的声音身份：年龄感、阅历、像在对谁讲述。第 5 步写全片统一的叙述语气
（如低沉克制、娓娓道来），不写某一段的情绪起伏。英文旁白写明口音（如 British RP、General American），
与中文描述保持同一叙述者气质，但要按英文重新写，不要直译中文。
