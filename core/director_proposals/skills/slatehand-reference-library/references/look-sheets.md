# 造型设定图

造型是角色图的唯一单位：每套造型有名称、外观、使用场合和一张选定的造型图。Keyframe 按造型为每帧选图。
增删改造型与选定造型图见 [library-edits.md](library-edits.md)。

## 版式

造型图可以是资产库已有的图片，也可以是 Core 生成的设定图（固定 2:1，柔和浅灰底）：左侧约四分之三为同一主体的
正面、正侧、背面与最能展示形态的第四个角度（人形取四分之三侧，伏地或多足生物取俯视），右侧约四分之一为头部正面特写。
版式不预设人形：主体完全由 `visual_description` 与 `appearance` 决定，非人生物会被要求按真实生物绘制、只画主体本身。
因此非人类角色的视觉描述必须写清物种与身体结构，造型外观不得写姿态或所处环境。

提示词默认由 Core 按角色 `visual_description` 与造型 `appearance` 编译，画幅、分辨率与版式也由 Core 处理。
只有用户要求或编译结果明显不能表达造型时，才用 `prompt_text` 提交完整提示词：Core 仍按 2:1 提交，但正文原样提交、
不再补版式与画幅句，所以必须自己写全版式要求，并遵守当前图片插件的提示词约定。

## 生成

只有用户明确要求时才生成：`generate_media` 使用 `kind: "look_sheet"`、`target_id` 为造型 ID、
`identity_asset_ids` 为身份参考图（0–4 张项目图片 Asset，可为空列表），可选 `prompt_text`。身份参考只保持脸部、
体型与年龄感，服装发型以本造型为准：

- 角色第一套造型通常不带身份参考，或只带用户提供的角色照片；
- 第一套造型图选定后，同一角色其余造型带上它作为身份参考，保证多套造型是同一个人。

每次调用只新增一张候选；想多看几张时多次调用。生成后用 `manage_generation` 的 `wait` 观察，完成后用
`read_media_input` 看图，按用户的要求用 `select_look_image` 选定最符合造型的一张，或交给用户在角色卡上选择。
用户和 Agent 都可以随时改选。
